# Vanya Living

Handcrafted furniture collection web application with 3D product previews, WhatsApp direct ordering, and an integrated product management console.

## Project Structure
- `VANYAPROD/index.html` - Customer storefront & catalog with 3D viewer & cart
- `VANYAPROD/productmanager.html` - Product & catalog management dashboard
- `VANYAPROD/assets/` - Media assets (brand logo, product 3D viewers, imagery, video)
- `vercel.json` - Vercel deployment configuration

## Deployment
Deployable directly on Vercel with zero configuration.
